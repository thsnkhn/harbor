## What Harbor can do

- Download files, public videos and audio, and torrents
- Pause, resume, and retry downloads
- Download multiple links at once
- Preview torrent files and choose what to download
- Set speed limits and organize downloads with tags
- Keep your download list between app launches

Harbor is free and open source. Your downloads stay on your Mac.

## Download

Install with Homebrew:

```sh
brew tap thsnkhn/harbor
brew install --cask harbor
```

Or download the latest DMG:

- Download the [latest DMG](https://github.com/thsnkhn/harbor/releases/latest) for your Mac's processor
- Drag `Harbor.app` into `Applications`

Harbor can check for updates from the app menu. It requires macOS 15.6 or later.

## Command line and agents

You can also manage downloads from a terminal or coding agent. Set this up in **Settings → General**. See the [CLI guide](docs/cli.md) for details.
